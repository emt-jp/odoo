🚗👥 HR Fleet Integration

Bridge module connecting HR and Fleet management with driver availability tracking, license management, and comprehensive driver dashboards with modern kanban views.

✨ Key Features

📊 Driver Dashboard

Kanban view of driver availability grouped by status with license state indicators and trip statistics.

🪪 License Management

Automated tracking of driver license validity with expiration alerts and status badges.

📍 Availability Tracking

Real-time driver status monitoring (Available, On Trip, On Leave, Off Duty) with visual indicators.

📈 Performance Metrics

Track driver trips, ratings, and performance statistics with badge displays.

🔗 Cross-Module Visibility

Integration status indicators showing connections between HR, Fleet, and Payroll modules.

🎨 Modern UI/UX

Kanban Dashboard Dual Status Badges License Alerts Visual Indicators Trip Statistics Responsive Cards

🔗 Integration

Serves as the integration layer between HR employees (drivers), Fleet vehicles (assignments), and Payroll (driver compensation). Provides unified driver management across all modules.

📦 Version

Version 1.0 - Compatible with Odoo 19.0
